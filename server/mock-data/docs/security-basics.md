# Security basics for project work

> Fictional policy for demo purposes.

- Turn on multi-factor authentication for every account you are given, on day one.
- Use only your company laptop for project work. Never copy project code or data to personal devices.
- Lock your screen whenever you step away.
- Treat unexpected emails asking for credentials or urgent payments as phishing. Report them; do not click links.
- Report a suspected incident (lost laptop, leaked password, data sent to the wrong person) to the security desk within one hour. Reporting quickly matters more than knowing every detail.
- Client systems may have their own stricter rules. Where rules differ, follow the stricter one.
