# Orion mobile release process

> Fictional document for demo purposes.

1. Feature branches are merged after review and passing tests.
2. A CI pipeline builds iOS and Android binaries with Expo.
3. Builds go to TestFlight and Google Play internal testing for the team and client testers.
4. Device-lab regression runs on the agreed device list.
5. The client approves the release; only named people with store publishing rights submit to the stores.
