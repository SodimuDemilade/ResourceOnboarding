# Handling client and personal data

> Fictional policy for demo purposes.

Personal data is anything that identifies a person: names, emails, account numbers, photos, device IDs.

- Client data stays in client systems. Do not paste it into personal notes, chat tools outside the client tenant, or AI tools that are not approved by the client.
- Use synthetic or masked data for development and testing. Never use production data in dev or test environments.
- Production access is granted only when necessary, for the shortest time, and is logged.
- If you are unsure whether data is sensitive, treat it as sensitive and ask your project lead.
