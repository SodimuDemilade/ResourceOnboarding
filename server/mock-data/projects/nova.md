# Project Nova: brief

> Fictional project for demo purposes.

## Goal
Nova is an internal tool that helps delivery teams track demo environments and their owners. It is a low-risk internal project often used to ramp up new joiners before they move to a client engagement.

## Technology
- React with TypeScript and Vite on the front end
- Node.js and Express API with PostgreSQL
- Deployed to an internal AWS staging account; code in our GitHub organisation

## Team and ways of working
One-week sprints, stand-up at 10:00 ET, async updates in team chat. No client NDA is needed.

## What new joiners typically work on
New joiners pick up small UI features and bug fixes, add tests, and pair with the tech lead during the first week. Business analysts on Nova gather feedback from internal users and maintain the backlog.
